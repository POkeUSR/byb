BYBIT SPOT SCANNER - 专业交易者指南

目的
----
这个扫描器是一个面向现货交易者的实时决策辅助工具。

它不是自动买卖机器人。
它不是预测系统。
它是一个早期异动扫描器，用来发现市场行为已经发生变化、但价格走势还没有完全明显的币种。

核心问题是：

"现在有哪些币值得马上打开图表检查？"


核心逻辑
--------
系统监听 Bybit Spot 的实时市场数据。

每个交易对都会分析：
- 实时价格；
- 成交记录；
- 短期成交量；
- bid/ask 深度；
- 订单簿环境；
- 价格和成交量历史；
- 相对 BTC 的强弱。

内部流程：

市场数据
-> 实时指标
-> score 计算
-> 原始信号
-> 市场环境分析
-> 结构和风险分类
-> alert 卡片
-> 可选的视觉图表分析


Score 的含义
------------
Score 表示当前活动相对于该币近期正常状态的异常程度。

Score 不是直接入场信号。
它的意思是：这个币需要检查。

Score 受以下因素影响：
- 成交量异常；
- 相对 BTC 的强度；
- 压缩或 squeeze；
- 吸收迹象；
- 短期价格行为；
- bid/ask 环境。

专业解释：

低 score：
通常不需要操作。

中等 score：
出现活动，可以加入观察列表。

高 score：
需要立即检查图表。

非常高 score：
可能进入动量阶段，但陷阱风险也更高。


信号卡片
--------
Score
当前信号强度。

Tier
setup 质量：
- A-TIER：结构强；
- B-TIER：可接受但不完美；
- C-TIER：弱、噪音大或风险高。

Status
信号生命周期：
- RAW：早期信号，尚未确认；
- CONFIRMED：走势得到确认；
- FAILED：没有继续；
- TRAP：可能是假突破或动量陷阱。

Risk
动态风险：
- LOW：结构更干净；
- MEDIUM：情况混合；
- HIGH：不稳定、过度拉升或危险。

Trap
假动量走势的概率。

Context
市场和结构解释：
- 市场状态；
- 相对强度；
- 突破质量；
- 结构状态；
- 系统评分原因。


专业工作流程
------------
不要因为出现 alert 就直接入场。

Alert 是过滤器。
图表才是决策界面。

建议流程：

1. 先查看 high-score 信号。
2. 打开 TradingView。
3. 检查 5m、15m、1h。
4. 标出局部区间。
5. 标出支撑和阻力。
6. 检查成交量是否延续。
7. 避免追高垂直拉升。
8. 对强信号或不清晰信号使用 visual-check。
9. 只有当结构确认时才考虑交易。


5m / 15m / 1h
-------------
5m
显示最近的触发点。

15m
显示走势是否真的有延续。

1h
显示更大级别环境。如果价格正好在 1h 阻力下方，5m 信号也可能风险较高。


好的现货 setup
--------------
较好的 long setup 通常具有：

- 高 score；
- A-TIER 或强 B-TIER；
- LOW 或 MEDIUM risk；
- 较低 trap 概率；
- 突破或重新站上重要水平；
- 第一波冲击后成交量继续；
- 15m 确认；
- 1h 上方没有很近的阻力；
- visual-check = CONFIRMED 或 WAIT 且触发条件清楚。


弱 setup
--------
以下情况应降低优先级或跳过：

- 价格已经垂直拉升；
- 出现长上影线；
- 成交量放大但没有延续；
- 价格在阻力位被拒绝；
- 15m 不确认；
- 1h 偏空或正处于阻力下方；
- trap 很高；
- visual-check = REJECTED。


Visual Check
------------
Visual-check 是手动的 GPT 图表辅助检查。

分析：
- 5m；
- 15m；
- 1h。

结果包括：
- 视觉状态；
- 入场质量；
- 风险；
- 各周期趋势；
- 总结；
- 原因；
- 失效条件；
- 下一步行动。

CONFIRMED
图表结构支持扫描器信号。

WAIT
信号有意思，但还需要等待确认。

REJECTED
结构不支持高质量入场。


专业决策规则
------------
最好的信号不一定是最高 score。

最好的信号是：

扫描器活动
+ 市场环境
+ 价格结构
+ 成交量延续
+ 风险控制

都指向同一方向。


核心原则
--------
扫描器负责发现值得关注的币。
图表负责确认结构。
交易者负责控制风险。

Alert 不是命令。
Alert 是专业观察列表触发器。
